2. Ganti file index.html lama dengan index.html dari paket ini.
3. Upload folder assets/img ke root repository, sejajar dengan index.html.
4. Isi folder assets/img dengan screenshot asli menggunakan nama file:

CATATAN:
- Bagian proyek lama berupa ikon folder dan link domain demo sudah diganti.
- Proyek sekarang ditampilkan sebagai kartu gambar di bagian #project.
- Klik screenshot untuk memperbesar; tidak membuka domain proyek.
- Screenshot asli belum disertakan karena belum dikirim. Jangan menggantinya dengan gambar ilustrasi yang tidak merepresentasikan aplikasi.
