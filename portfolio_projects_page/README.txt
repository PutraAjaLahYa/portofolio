PORTOFOLIO PROYEK - PUTRA BARUTA

CARA MEMASANG
1. Salin projects.html ke folder website portofolio kamu.
2. Salin folder assets beserta subfolder img ke lokasi yang sama.
3. Masukkan screenshot ASLI proyek ke assets/img dengan nama file berikut:
   benteng-hulu.jpg
   alamak-pos.jpg
   yasaka.jpg
   showroom.jpg
   lstm-gru.jpg
   kalkulator.jpg
   kalkulator-ipk.jpg
   homestay.jpg
   perpustakaan.jpg
4. Buka projects.html melalui browser atau tautkan dari menu website lama.

PENTING
- Halaman ini tidak membuka domain demo proyek. Gambar ditampilkan langsung dari file lokal.
- Gambar belum disertakan karena screenshot asli tiap aplikasi belum diberikan.
- Gunakan screenshot milik sendiri/yang diizinkan untuk ditampilkan.
- Kartu dan tombol "Lihat gambar" akan membuka pratinjau gambar besar (lightbox).
